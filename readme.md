# Lockr

**Generate Strong. Stay Secure.**

Lockr is a modern, responsive password generator designed to help users create strong and customizable passwords quickly and easily.

## ✨ Features

* 🔑 Generate random, secure passwords
* 📏 Customize password length
* 🔠 Include uppercase and lowercase letters
* 🔢 Include numbers
* 🔣 Include special characters
* 💪 Real-time password strength indicator
* 📋 Copy passwords to clipboard
* 🕘 View recently generated passwords
* 📱 Fully responsive design for desktop and mobile
* 🌙 Modern dark-themed interface

## 🛠️ Built With

* **HTML5** — Website structure
* **CSS3** — Styling, layout, animations, and responsive design
* **JavaScript** — Password generation and interactive functionality

## 🚀 Getting Started

No installation or dependencies are required.

1. Clone the repository:

```bash
git clone https://github.com/your-username/lockr.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it — Lockr is ready to use.

## 🔒 Privacy

Lockr is designed around local password generation. Generated passwords are handled within the browser and are not intentionally sent to an external server.

> **Important:** Generated passwords should still be handled carefully and should not be shared with anyone.
